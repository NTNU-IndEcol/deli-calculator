# Food Carbon Footprint Calculator

This is a simple web app to calculate the carbon footprint of food based on user input (ingredients, amount, unit, and import location).

## How to Use

1. **Clone the Repository**:
   ```bash
   git clone <repository-url>
   cd deli-calculator/app
   ```
2. **Run the app**: 
   '''
   python app.py  
   '''
